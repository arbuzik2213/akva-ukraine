## 📱 Ключові можливості застосунку

1. **📊 Графіки та оперативні статуси водопостачання по Україні:**
   - Моніторинг аварійних проривів, планових ремонтів та гідравлічних випробувань.
   - Дані відкритих служб: **Київводоканал (1581)**, **Львівводоканал (1580)**, **Дніпроводоканал**, **Інфоксводоканал Одеса**, **Харківводоканал** та інших міст.
   - Візуальний інтерактивний **24-годинний графік** наявності води та тиску в мережі (3.2 бар / 1.1 бар / 0.0 бар).
   - Врахування знеструмлення підкачувальних насосних станцій під час графіків вимкнення світла.

2. **🔔 Віджет SMS та Пуш-нагадувань (за 10 хв, 30 хв, 1 год):**
   - Налаштування завчасних попереджень:
     - ⏱ **За 30 хвилин:** нагадування набрати резервний запас води.
     - 🚨 **За 10 хвилин:** екстрене сповіщення перед вимкненням насосів.
     - 💧 **При відновленні:** миттєве сповіщення про повернення тиску в норму.
   - **Інтерактивний SMS-симулятор:** тестування та перегляд вигляду термінових SMS у шторці сповіщень.

3. **📲 Віджет робочого столу (Home Screen Widget):**
   - Вбудований демонстратор та конфігуратор віджетів різного розміру:
     - **Малий (2x2):** статус тиску та іконка краплі.
     - **Середній (4x2):** адреса, статус, зворотний відлік до відновлення води.
     - **Великий (4x4):** детальний огляд мережі, гаряча лінія диспетчерської та стан водогону.

4. **🗺 Мапа та список пунктів питної води:**
   - Артезіанські бюветні комплекси.
   - Чергові міські автоцистерни з технічною та питною водою.
   - Пункти Незламності з резервуарами питної води та генераторами.

5. **🎨 Преміальний дизайн та теми:**
   - Світла тема (Light) ☀️
   - Темна тема (Dark OLED) 🌙
   - Як у системі (System Default) ⚙️
   - Сучасний, стриманий стиль у дусі *«Дія»* та *«Київ Цифровий»*.

6. **🌍 Багатомовність (6 мов, БЕЗ російської):**
   - 🇺🇦 **Українська** (Основна)
   - 🇬🇧 **English**
   - 🇵🇱 **Polski**
   - 🇩🇪 **Deutsch**

## 🚀 Як зібрати APK через GitHub Actions (Без встановлення Flutter на комп'ютер)

У проєкті вже налаштований готовий CI/CD workflow у файлі [`.github/workflows/build.yml`](.github/workflows/build.yml). Вам достатньо опублікувати код у свій репозиторій на GitHub.

### Крок 1. Створіть новий репозиторій на GitHub
1. Перейдіть на [github.com/new](https://github.com/new).
2. Назвіть репозиторій, наприклад: `akva-ukraine` (можна зробити публічним або приватним).
3. **Не** додавайте README чи .gitignore під час створення на сайті, оскільки вони вже готові в проєкті.

### Крок 2. Запушіть проєкт у GitHub
У терміналі в папці проєкту виконайте:

```bash
git init
git add .
git commit -m "feat: initial commit AquaAlert UA"
git branch -M main
git remote add origin https://github.com/<ВАШ_ГІТХАБ_ЛОГІН>/akva-ukraine.git
git push -u origin main
```

### Крок 3. Автоматична збірка APK у GitHub Actions
1. Відкрийте ваш репозиторій на GitHub і перейдіть у вкладку **Actions**.
2. Ви побачите запущений пайплайн **«Build & Release AquaAlert UA»**.
3. GitHub автоматично запустить віртуальну машину Ubuntu, завантажить Flutter, скомпілює код і збере:
   - 📦 **Universal Release APK** (`app-release.apk`) — підходить для будь-якого Android-смартфона.
   - ⚡ **Split-per-ABI APKs** (`arm64-v8a`) — полегшена версія для сучасних смартфонів.
   - 🛍 **Google Play App Bundle** (`app-release.aab`) — готовий файл для публікації в Google Play Console.
   - 🍏 **iOS Runner** — перевірка компіляції під iOS.

### Крок 4. Завантаження готового APK на телефон
1. Після завершення збірки (зелена галочка ✅) натисніть на відповідний запуск у вкладці **Actions**.
2. Прокрутіть сторінку вниз до розділу **Artifacts**.
3. Натисніть на `akva-ukraine-universal-apk` — завантажиться zip-архів з файлом `app-release.apk`.
4. Скиньте файл на телефон або надішліть собі в Telegram і встановіть!

> 💡 **Створення офіційного GitHub Release:**
> Якщо створити Git тег:
> ```bash
> git tag v1.0.0
> git push origin v1.0.0
> ```
> GitHub Actions автоматично створить сторінку **Releases** з прямими посиланнями на завантаження APK без необхідності розпаковувати zip-архіви!

## 🛠 Локальний запуск (для розробників)

Якщо ви бажаєте протестувати проєкт локально на своєму комп'ютері:

```bash
# 1. Отримати залежності
flutter pub get

# 2. Запустити в режимі розробки
flutter run

# 3. Ручна збірка APK
flutter build apk --release
```
